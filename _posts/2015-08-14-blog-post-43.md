Background
======
Inflammatory bowel diseases (IBDs), including ulcerative colitis and Crohn’s disease, are chronic relapsing inflammatory disorders of the gastrointestinal tract characterized by epithelial barrier disruption, immune dysregulation, and microvascular remodeling. Although epithelial and immune cells have been widely studied as central drivers of intestinal inflammation, emerging evidence has highlighted the endothelium as a key regulator of gut homeostasis and inflammation. Intestinal endothelial cells (ECs) form a highly specialized vascular network that regulates leukocyte trafficking, nutrient exchange, and vascular permeability. During inflammation, ECs undergo profound phenotypic and functional alterations, including the upregulation of adhesion molecules (e.g., ICAM1, VCAM1), pro-inflammatory cytokines (e.g., IL6, CXCL1), and angiogenic factors, thereby actively shaping the tissue microenvironment and immune cell recruitment.<br/>

In the context of colitis, ECs not only respond to cytokine cues from innate and adaptive immune cells but also contribute to chronicity and tissue damage by sustaining inflammatory signaling. Notably, recent studies have suggested that endothelial dysfunction precedes histological signs of colitis, implying a potential initiating or amplifying role for ECs in disease pathogenesis. However, most of our current understanding is based on bulk transcriptomic or immunohistochemical analyses, which obscure cellular heterogeneity and dynamic endothelial states under inflammatory stress.<br/>

The dextran sulfate sodium (DSS)–induced colitis model remains one of the most widely used systems to mimic human ulcerative colitis due to its reproducibility and pathological similarity. Repeated cycles of DSS administration induce a chronic, relapsing-remitting form of colitis, closely resembling the clinical course of IBD. Nevertheless, how intestinal ECs adapt to sequential inflammatory insults—whether they acquire memory-like phenotypes, undergo irreversible reprogramming, or contribute to aberrant angiogenesis—remains poorly understood. Furthermore, the potential existence of inflammation-associated endothelial subsets with specialized functions, such as antigen presentation, lymphocyte retention, or barrier modulation, has yet to be fully delineated.<br/>

Recent advances in single-cell RNA sequencing (scRNA-seq) provide an unprecedented opportunity to resolve the cellular complexity of the intestinal microenvironment, enabling the identification of rare or transient EC subsets, trajectory inference of state transitions, and mapping of cell–cell communication networks during disease progression. By applying scRNA-seq to endothelial-enriched fractions of colonic tissues from mice subjected to two cycles of DSS treatment, this study aims to capture the transcriptional plasticity, subset diversification, and molecular programs of ECs in response to repeated inflammatory challenges. This approach offers critical insights into how the vasculature integrates and amplifies inflammatory signals and may uncover endothelial biomarkers or therapeutic targets relevant to chronic colitis and mucosal healing.<br/>

import scanpy as sc

# Load the single-cell dataset from the specified h5ad file
adata = sc.read_h5ad('/data1/zengmin/SC-RNA-seq/DSS_python/adata.h5ad')


# Subset endothelial cells based on Leiden clustering annotation
# Extract vascular endothelial cells
adata_vascular = adata[adata.obs['leiden_0.3'] == 'Vascular endothelial cells'].copy()

# Extract lymphatic endothelial cells
adata_lymphatic = adata[adata.obs['leiden_0.3'] == 'Lymphatic endothelial cells'].copy()

# Extract all endothelial cells including both vascular and lymphatic types
adata_endothelial = adata[adata.obs['leiden_0.3'].isin(['Vascular endothelial cells', 'Lymphatic endothelial cells'])].copy()


# Perform re-clustering analysis on the endothelial subset

# Scale the data matrix, capping maximum value to reduce influence of outliers
sc.pp.scale(adata_endothelial, max_value=10)

# Perform principal component analysis (PCA) for dimensionality reduction
sc.tl.pca(adata_endothelial, svd_solver='arpack')

# Plot the variance ratio explained by each principal component (log scale)
# to help select the number of components for downstream analysis
sc.pl.pca_variance_ratio(adata_endothelial, log=True)

# Compute neighborhood graph of observations using the selected PCs
sc.pp.neighbors(adata_endothelial, n_neighbors=15, n_pcs=10)

# Perform Leiden clustering with a specified resolution parameter
# to identify fine-grained endothelial subpopulations
sc.tl.leiden(adata_endothelial, resolution=0.4)

# Compute UMAP coordinates for 2D visualization of the endothelial cell landscape
sc.tl.umap(adata_endothelial)

# Visualize UMAP colored by Leiden clusters
sc.pl.umap(adata_endothelial, color=['leiden'])


# Rename Leiden clusters to biologically meaningful endothelial cell types
leiden_to_celltype = {
    '1': 'Lymphatic Endothelial Cells',
    '2': 'Lymphatic Endothelial Cells',
    '3': 'Lymphatic Endothelial Cells',
    '4': 'Lymphatic Endothelial Cells',

# Map the original Leiden cluster labels to new cell type annotations

import matplotlib.pyplot as plt

# Prepare a figure grid: 2 rows, 4 columns, adjusted size for clarity
fig, axs = plt.subplots(2, 4, figsize=(20, 10))

# Volcano plot annotation for selected comparison group (e.g., R1 D7 vs R1 D0)

import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

# Define comparison group and thresholds for significance and fold change
group = 'R1 D7'
padj_thresh = 0.05
logfc_cap = 10    # Maximum log fold change to display
top_n = 10        # Number of top genes to label on plot

# Extract DEG results from the AnnData object
de_result = adata_vascular.uns['rank_genes_groups']

volcano_df = pd.DataFrame({
    'gene': de_result['names'][group],
    'logfoldchanges': de_result['logfoldchanges'][group],
    'pvals_adj': de_result['pvals_adj'][group]
})

# Calculate negative log10 adjusted p-values for volcano plot y-axis
volcano_df['-log10(padj)'] = -np.log10(volcano_df['pvals_adj'])

# Filter for significant genes with reasonable fold change range
filtered_df = volcano_df[
    (volcano_df['pvals_adj'] < padj_thresh) &
    (np.abs(volcano_df['logfoldchanges']) < logfc_cap)
].copy()

# Label genes as significant if absolute logFC > 1
filtered_df['significant'] = np.abs(filtered_df['logfoldchanges']) > 1

# Generate volcano plot using seaborn scatterplot
plt.figure(figsize=(8, 6))
sns.scatterplot(
    data=filtered_df,
    x='logfoldchanges',
    y='-log10(padj)',
    hue='significant',
    palette={True: 'red', False: 'grey'},
    edgecolor=None,
    alpha=0.8
)

# Add vertical and horizontal cutoff lines for significance and fold change
plt.axvline(x=1, color='black', linestyle='--')
plt.axvline(x=-1, color='black', linestyle='--')
plt.axhline(y=-np.log10(padj_thresh), color='black', linestyle='--')

# Annotate the top N most significant genes by adjusted p-value
top_genes = filtered_df.sort_values('pvals_adj').head(top_n)
for _, row in top_genes.iterrows():
    plt.text(
        row['logfoldchanges'],
        row['-log10(padj)'],
        row['gene'],
        fontsize=10,
        ha='right' if row['logfoldchanges'] < 0 else 'left'
    )

# Set plot titles and labels
plt.title(f'Volcano plot (filtered, labeled): {group} vs R1 D0')
plt.xlabel('Log2 Fold Change')
plt.ylabel('-Log10 Adjusted p-value')
plt.legend(title='Log2FC > 1 & Padj < 0.05')
plt.tight_layout()
plt.show()
